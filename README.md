# paoloscotto.it

Portfolio fotografico di Paolo Scotto di Vettimo.

## Struttura

```
paoloscotto-site/
├── index.html          ← sito completo
├── netlify.toml        ← configurazione Netlify
├── admin/
│   ├── index.html      ← pannello CMS (paoloscotto.it/admin)
│   └── config.yml      ← struttura contenuti CMS
└── foto/
    ├── hero.jpg        ← foto landing page
    ├── editorial/      ← cover e gallerie editoriali
    └── reportage/      ← cover e gallerie reportage
```

## Come aggiungere una foto

1. Vai su `paoloscotto.it/admin`
2. Seleziona il progetto
3. Carica la foto — viene salvata automaticamente in `/foto/`

## Come aggiungere un progetto

1. Vai su `paoloscotto.it/admin`
2. Clicca su "Editorial" o "Reportage"
3. Clicca "New" — compila e pubblica
